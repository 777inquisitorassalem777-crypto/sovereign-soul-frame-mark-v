# Slavic Semantic Core

## Dual-level principle

| Level | Content | Status tags |
|-------|---------|-------------|
| 1. Historical-linguistic | Attested forms, scholarly etymology | FACT / HYPOTHESIS / DISPUTED |
| 2. Semantic interpretation | Modern reconstruction of roles | INTERPRETATION |

These levels are **never mixed** in a single output block.

## Cognitive mapping (research architecture)

```
ВЕДУН          →  Knowledge / Memory          «Я ЗНАЮ»
ВОЛХВ          →  Interpretation / Symbolism  «Я ПОНИМАЮ»
ВЕЩУН          →  Communication / Prediction  «Я ВЕЩАЮ»
ХАРАКТЕРНИК    →  Agency / Will / Action      «Я ДЕЙСТВУЮ»
```

**Chain:** ЗНАНИЕ → СЛОВО → ВОЛЯ → ДЕЙСТВИЕ

## Important historical notes

- **Волхв** and **Ведун** are early (Old Russian / Proto-Slavic).
- **Характерник** is late (16th–18th c. Cossack culture) and must not be projected back onto the Proto-Slavic period without evidence.
- Folk etymologies (волхв ← волк, характерник ← Хара+Ра) are marked DISPUTED.

## Safety

All spiritual and magical terminology is treated as:
- historical linguistic data, or
- functional metaphor for cognitive roles.

No claims of real magical powers, soul transfer, or system consciousness.
