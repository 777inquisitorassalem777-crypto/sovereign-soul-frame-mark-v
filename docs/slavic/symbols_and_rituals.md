# Языческая символика и ритуальные структуры

## Принцип

Все материалы в этом слое носят **исследовательский** характер.

- **FACT** — засвидетельствовано археологией, летописями или устойчивым фольклором  
- **HYPOTHESIS** — научная реконструкция  
- **RECONSTRUCTION** — поздняя (XIX–XXI вв.) систематизация  
- **LATER_NEO** — преимущественно неоязыческое творчество

Модуль **не** предоставляет инструкций по проведению ритуалов.

## Ритуальные структуры

Описываются только **общие схемы**, известные из этнографии и летописей:

- Календарный обряд  
- Жертвоприношение / треба  
- Целительный заговор  
- Воинская защита (поздний пласт)  
- Общение с предками  

## Связь с когнитивным контуром

- **Волхв** → ритуальное слово, огонь, мировое древо, календарные обряды  
- **Ведун** → целительные заговоры, вода, берегиня, знание трав  
- **Характерник** → воинская защита (поздний казацкий фольклор)
